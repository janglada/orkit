    Examples¶

    Seven complete programs, one per domain. Each one is larger than the snippets on the domain pages and prints a readable report, so they are a good place to see how the pieces fit together.

    New here?

    Start with the small examples instead: Getting started has a first program explained line by line, and every domain page opens with a quick start.

    How to run them¶

    The examples live in the test sources of the project (src/test/java/io/github/janglada/orkit/examples), so they are not part of the library jar. From the project folder, run one with Maven:

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.PcbManufacturingJobShop

    Replace the last word with the name of the example you want.

    The seven examples¶

    Example Domain The story
    PcbManufacturingJobShop Job-shop A factory makes eight kinds of circuit board on five machines. Some steps can run on either of two machines. The program finds the fastest schedule and prints a timetable per machine.
    HospitalNurseScheduling Shift scheduling Twelve nurses cover 21 shifts in one week, with skills, rest rules and preferences, at the lowest labor cost.
    BarcelonaDeliveryVrp Vehicle routing Four vans deliver to 18 addresses with opening hours, limited capacity, a distance limit and driver breaks.
    CargoLoadingMultipleKnapsack Multiple knapsack Nine cargo lots compete for three containers. The program loads the most valuable combination.
    WarehouseContainerPacking Container packing Eight boxes are placed in two containers in 3D, using as few containers as possible.
    ClinicAppointmentBooking Resource booking Eight appointments share three rooms. One of them also needs a surgeon. The least important ones are left out when space runs short.
    SteelRollCuttingStock Cutting stock Beams of five lengths are cut from three kinds of stock with a 3 mm blade, wasting as little steel as possible.

    Click "Source" under an example to read its full code.

    PCB flexible job shop¶

    A factory makes eight kinds of circuit board on five machines. Some steps can run on either of two pick-and-place machines, and the solver chooses. The goal is to finish everything as early as possible. The program prints the timetable of each machine.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.PcbManufacturingJobShop
    Source: PcbManufacturingJobShop.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.Optimize;
import io.github.janglada.orkit.jobshop.Gantt;
import io.github.janglada.orkit.jobshop.JobShopSchedule;
import io.github.janglada.orkit.jobshop.ScheduledOperation;

import java.time.Duration;
import java.util.List;

/**
 * PCB electronics manufacturing — flexible job shop with 8 board types and 5 machines.
 *
 * Demonstrates: flexible operations (onAnyOf), multiple jobs sharing machines,
 * makespan minimization, Gantt chart output.
 *
 * Machines:
 *   SCREEN    — solder-paste screen printing
 *   PP1, PP2  — pick-and-place (two identical machines, flexible assignment)
 *   REFLOW    — reflow oven (solders components)
 *   AOI       — automated optical inspection
 *
 * Each board type (job) follows: SCREEN → PP1|PP2 (flexible) → REFLOW → AOI
 * Duration varies by board complexity (in minutes).
 *
 * Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.PcbManufacturingJobShop
 */
public class PcbManufacturingJobShop {

    /**
     * Builds the PCB flexible job-shop model, solves it with CP-SAT, and prints the
     * makespan, per-machine Gantt chart, and the pick-and-place machine assignments.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═════════════════════════════════════════════╗");
        System.out.println("║   PCB Manufacturing — Flexible Job Shop     ║");
        System.out.println("╚═════════════════════════════════════════════╝");

        JobShopSchedule schedule = Optimize.jobShop()
                .machines("SCREEN", "PP1", "PP2", "REFLOW", "AOI")

                // Standard boards (mid complexity)
                .job("Standard-A", j -> j
                        .operation().on("SCREEN").takes(8)
                        .then().onAnyOf("PP1", "PP2").takes(12)
                        .then().on("REFLOW").takes(20)
                        .then().on("AOI").takes(5))

                .job("Standard-B", j -> j
                        .operation().on("SCREEN").takes(8)
                        .then().onAnyOf("PP1", "PP2").takes(10)
                        .then().on("REFLOW").takes(20)
                        .then().on("AOI").takes(5))

                .job("Standard-C", j -> j
                        .operation().on("SCREEN").takes(8)
                        .then().onAnyOf("PP1", "PP2").takes(14)
                        .then().on("REFLOW").takes(20)
                        .then().on("AOI").takes(5))

                // Complex boards (many components → longer pick-and-place)
                .job("Complex-X", j -> j
                        .operation().on("SCREEN").takes(10)
                        .then().onAnyOf("PP1", "PP2").takes(28)
                        .then().on("REFLOW").takes(25)
                        .then().on("AOI").takes(8))

                .job("Complex-Y", j -> j
                        .operation().on("SCREEN").takes(10)
                        .then().onAnyOf("PP1", "PP2").takes(32)
                        .then().on("REFLOW").takes(25)
                        .then().on("AOI").takes(8))

                // Prototype boards (double reflow pass for reliability)
                .job("Proto-1", j -> j
                        .operation().on("SCREEN").takes(12)
                        .then().onAnyOf("PP1", "PP2").takes(18)
                        .then().on("REFLOW").takes(40)   // double pass
                        .then().on("AOI").takes(10))

                .job("Proto-2", j -> j
                        .operation().on("SCREEN").takes(12)
                        .then().onAnyOf("PP1", "PP2").takes(22)
                        .then().on("REFLOW").takes(40)   // double pass
                        .then().on("AOI").takes(10))

                // Rush order — simple board but must fit in the schedule
                .job("Rush-Order", j -> j
                        .operation().on("SCREEN").takes(6)
                        .then().onAnyOf("PP1", "PP2").takes(8)
                        .then().on("REFLOW").takes(18)
                        .then().on("AOI").takes(4))

                .solver()
                .timeLimit(Duration.ofSeconds(30))
                .workers(8)
                .solve();

        // ── Results ───────────────────────────────────────────────────────────
        System.out.printf("%nStatus  : %s%n", schedule.status());
        System.out.printf("Makespan: %d minutes (%.1f hours)%n",
                schedule.makespan(), schedule.makespan() / 60.0);
        schedule.bestBound().ifPresent(b -> System.out.printf("Bound   : %.0f minutes (gap %.1f%%)%n",
                b, 100 * schedule.gap().orElse(0)));
        System.out.println();

        // Gantt chart per machine
        Gantt gantt = schedule.asGantt();
        System.out.println("── Gantt Chart (time in minutes) ─────────────────────────────────────");
        System.out.printf("%-10s  %-14s  %-10s  %-10s  %-10s%n",
                "Machine", "Job", "Start", "End", "Duration");
        System.out.println("-".repeat(62));

        for (String machine : gantt.machines()) {
            List<ScheduledOperation> ops = gantt.rowFor(machine);
            if (ops.isEmpty()) continue;
            for (ScheduledOperation op : ops) {
                System.out.printf("%-10s  %-14s  %-10d  %-10d  %-10d%n",
                        machine, op.job(), op.start(), op.end(), op.end() - op.start());
            }
            System.out.println();
        }

        // Validate: PP1/PP2 flexible assignments
        System.out.println("── Pick-and-Place machine assignments ────────────────────────────────");
        String[] jobs = {"Standard-A","Standard-B","Standard-C","Complex-X","Complex-Y","Proto-1","Proto-2","Rush-Order"};
        for (String job : jobs) {
            ScheduledOperation ppOp = schedule.operationsOf(job).get(1); // index 1 = PP step
            System.out.printf("  %-14s → %s (start=%d, end=%d)%n",
                    job, ppOp.machine(), ppOp.start(), ppOp.end());
        }
    }
}

    Hospital weekly nurse roster¶

    Twelve nurses cover 21 shifts over one week. The model uses skills, rest rules and personal preferences, and looks for the roster with the lowest labor cost.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.HospitalNurseScheduling
    Source: HospitalNurseScheduling.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.Optimize;
import io.github.janglada.orkit.SolveStatus;
import io.github.janglada.orkit.scheduling.EmployeeRoster;
import io.github.janglada.orkit.scheduling.ShiftAssignment;

import java.time.DayOfWeek;
import java.time.Duration;
import java.time.LocalDate;
import java.time.LocalTime;
import java.util.*;

import static io.github.janglada.orkit.scheduling.Goals.*;
import static io.github.janglada.orkit.scheduling.Rules.*;

/**
 * Hospital weekly nurse scheduling — 12 nurses, 21 shifts (day/evening/night × 7 days).
 *
 * Demonstrates: multi-day horizon, skill tiers, multiple shift types per day,
 * rest and consecutive-day rules, balanced workload, labor cost minimization.
 *
 * Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.HospitalNurseScheduling
 */
public class HospitalNurseScheduling {

    // Shift codes — 3 per day × 7 days = 21 shifts
    private static final String[] DAYS = {"Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"};
    private static final DayOfWeek[] DOW = {
        DayOfWeek.MONDAY, DayOfWeek.TUESDAY, DayOfWeek.WEDNESDAY,
        DayOfWeek.THURSDAY, DayOfWeek.FRIDAY, DayOfWeek.SATURDAY, DayOfWeek.SUNDAY
    };
    private static final LocalDate WEEK_START = LocalDate.of(2026, 7, 6); // Monday

    /**
     * Builds the weekly ICU nurse-rostering model, solves it with CP-SAT, and prints
     * the roster grid, ICU night-shift coverage, and per-nurse workload statistics.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═══════════════════════════════════════════════╗");
        System.out.println("║      Hospital ICU Ward — Weekly Roster        ║");
        System.out.println("╚═══════════════════════════════════════════════╝");

        var builder = Optimize.scheduling().horizon(WEEK_START, 7);

        // ── Nurses ──────────────────────────────────────────────────────────
        // 4 Senior nurses (ICU + RN)
        builder.employee("Dr. Alice",  e -> e.skills("RN","ICU").costPerHour(58).maxHoursPerWeek(40).prefersShift("Mon-Day"))
               .employee("Dr. Bob",    e -> e.skills("RN","ICU").costPerHour(55).maxHoursPerWeek(40).prefersShift("Tue-Day"))
               .employee("Dr. Carol",  e -> e.skills("RN","ICU").costPerHour(56).maxHoursPerWeek(40))
               .employee("Dr. Dave",   e -> e.skills("RN","ICU").costPerHour(54).maxHoursPerWeek(36));

        // 5 Staff nurses (RN only)
        builder.employee("Nurse Eve",   e -> e.skills("RN").costPerHour(42).maxHoursPerWeek(40))
               .employee("Nurse Frank", e -> e.skills("RN").costPerHour(40).maxHoursPerWeek(40).prefersShift("Mon-Day"))
               .employee("Nurse Grace", e -> e.skills("RN").costPerHour(38).maxHoursPerWeek(36))
               .employee("Nurse Hank",  e -> e.skills("RN").costPerHour(39).maxHoursPerWeek(40))
               .employee("Nurse Iris",  e -> e.skills("RN").costPerHour(41).maxHoursPerWeek(40));

        // 3 Part-time nurses (RN, limited to weekdays)
        builder.employee("PT Jane",     e -> e.skills("RN").costPerHour(44)
                       .availableOn(DayOfWeek.MONDAY, DayOfWeek.TUESDAY, DayOfWeek.WEDNESDAY,
                                    DayOfWeek.THURSDAY, DayOfWeek.FRIDAY).maxHoursPerWeek(24))
               .employee("PT Kevin",    e -> e.skills("RN").costPerHour(43)
                       .availableOn(DayOfWeek.MONDAY, DayOfWeek.WEDNESDAY, DayOfWeek.FRIDAY).maxHoursPerWeek(24))
               .employee("PT Laura",    e -> e.skills("RN").costPerHour(45)
                       .availableOn(DayOfWeek.TUESDAY, DayOfWeek.THURSDAY).maxHoursPerWeek(16));

        // ── Shifts: Day 07-15, Evening 15-23, Night 23-07 ───────────────────
        // Day and evening each need 2 RN; Night needs 1 ICU + 1 RN
        for (int i = 0; i < 7; i++) {
            final int idx = i;
            String label = DAYS[i];
            DayOfWeek dow = DOW[i];

            builder.shift(label + "-Day", s -> s
                    .on(dow).from(LocalTime.of(7, 0)).to(LocalTime.of(15, 0))
                    .needs(2).withSkill("RN"));
            builder.shift(label + "-Evening", s -> s
                    .on(dow).from(LocalTime.of(15, 0)).to(LocalTime.of(23, 0))
                    .needs(2).withSkill("RN"));
            builder.shift(label + "-Night", s -> s
                    .on(dow).from(LocalTime.of(23, 0)).to(LocalTime.of(7, 0))
                    .needs(1).withSkill("ICU"));
        }

        // ── Rules ─────────────────────────────────────────────────────────────
        builder.constrain(oneShiftPerEmployeePerDay())
               .constrain(minRestBetweenShifts(Duration.ofHours(11)))
               .constrain(maxConsecutiveWorkDays(5));

        // ── Goals ─────────────────────────────────────────────────────────────
        builder.prefer(balanceWorkloadAcrossEmployees())
               .prefer(honorEmployeePreferences())
               .goal(totalLaborCost());

        // ── Solve ─────────────────────────────────────────────────────────────
        System.out.println("\nSolving (30 s time limit, 8 workers)…");
        long t0 = System.currentTimeMillis();

        EmployeeRoster roster = builder.solver()
                .timeLimit(Duration.ofSeconds(30))
                .workers(8)
                .verbose(false)
                .solve();

        long elapsed = System.currentTimeMillis() - t0;

        // ── Results ───────────────────────────────────────────────────────────
        System.out.printf("%nStatus : %s  (solved in %.1fs)%n", roster.status(), elapsed / 1000.0);
        if (!roster.isFeasible()) {
            System.out.println("No feasible roster found.");
            return;
        }

        System.out.printf("Cost   : $%.2f labor%n", roster.laborCost());
        roster.gap().ifPresent(g -> System.out.printf("Gap    : %.2f%%%n", 100 * g));

        // Print roster grid: rows = nurses, cols = days, cells = shift type
        System.out.println();
        printRoster(roster);
        printStatistics(roster);
    }

    private static void printRoster(EmployeeRoster roster) {
        String[] nurses = {
            "Dr. Alice", "Dr. Bob", "Dr. Carol", "Dr. Dave",
            "Nurse Eve", "Nurse Frank", "Nurse Grace", "Nurse Hank", "Nurse Iris",
            "PT Jane", "PT Kevin", "PT Laura"
        };

        // Header
        System.out.printf("%-15s", "Nurse \\ Day");
        for (String d : DAYS) System.out.printf(" %-9s", d);
        System.out.println();
        System.out.println("-".repeat(15 + 10 * 7));

        for (String nurse : nurses) {
            System.out.printf("%-15s", nurse);
            for (String d : DAYS) {
                List<String> nurseShifts = roster.shiftsFor(nurse);
                String cell = "";
                if (nurseShifts.contains(d + "-Day"))     cell = "Day";
                else if (nurseShifts.contains(d + "-Evening")) cell = "Eve";
                else if (nurseShifts.contains(d + "-Night"))   cell = "Ngt";
                System.out.printf(" %-9s", cell.isEmpty() ? "." : cell);
            }
            int totalH = roster.shiftsFor(nurse).size() * 8;
            System.out.printf("  (%dh)%n", totalH);
        }
    }

    private static void printStatistics(EmployeeRoster roster) {
        System.out.println("\n── ICU night shift coverage ─────────────────────");
        for (String day : DAYS) {
            List<String> staff = roster.staffOf(day + "-Night");
            System.out.printf("  %-4s Night ICU: %s%n", day, String.join(", ", staff));
        }

        System.out.println("\n── Workload per nurse ────────────────────────────");
        String[] nurses = {
            "Dr. Alice", "Dr. Bob", "Dr. Carol", "Dr. Dave",
            "Nurse Eve", "Nurse Frank", "Nurse Grace", "Nurse Hank", "Nurse Iris",
            "PT Jane", "PT Kevin", "PT Laura"
        };
        for (String nurse : nurses) {
            int shifts = roster.shiftsFor(nurse).size();
            System.out.printf("  %-15s %d shift(s) = %dh%n", nurse, shifts, shifts * 8);
        }
    }
}

    Barcelona parcel delivery¶

    Four vans deliver to 18 addresses. Customers have opening hours, vans have limited capacity and a distance limit, and drivers take a break. The search builds first routes with the SAVINGS method and improves them with guided local search.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.BarcelonaDeliveryVrp
    Source: BarcelonaDeliveryVrp.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.Optimize;
import io.github.janglada.orkit.routing.*;

import java.time.Duration;
import java.time.LocalTime;
import java.util.List;

/**
 * Morning parcel delivery across Barcelona — 4 vehicles, 18 stops, time windows.
 *
 * Demonstrates: realistic lat/lon coordinates, multiple vehicles with different
 * capacities, time windows in two cohorts, haversine distances, SAVINGS + GLS.
 *
 * Depot: Mercabarna logistics hub (Zona Franca)
 * Stops: hotels, supermarkets, and restaurant groups across Barcelona neighborhoods.
 *
 * Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.BarcelonaDeliveryVrp
 */
public class BarcelonaDeliveryVrp {

    /**
     * Builds the Barcelona delivery VRP model, solves it with the {@code SAVINGS}
     * first solution followed by guided local search, and prints the routes,
     * vehicle utilization, and any stops that could not be assigned.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═══════════════════════════════════════════════════╗");
        System.out.println("║   Barcelona Morning Delivery — Vehicle Routing    ║");
        System.out.println("╚═══════════════════════════════════════════════════╝");

        RoutingPlan plan = Optimize.vehicleRouting()

                // Mercabarna logistics hub — Zona Franca
                .depot("Mercabarna", 41.3473, 2.1260)

                // Fleet: 2 large vans + 2 small vans
                .vehicle("LargeVan-1",  v -> v.capacity(25).maxDistanceMeters(60_000)
                        .breakBetween(LocalTime.of(12, 0), LocalTime.of(14, 0), Duration.ofMinutes(30)))
                .vehicle("LargeVan-2",  v -> v.capacity(25).maxDistanceMeters(60_000)
                        .breakBetween(LocalTime.of(12, 0), LocalTime.of(14, 0), Duration.ofMinutes(30)))
                .vehicle("SmallVan-1",  v -> v.capacity(15).maxDistanceMeters(50_000))
                .vehicle("SmallVan-2",  v -> v.capacity(15).maxDistanceMeters(50_000))

                // ── Morning wave (08:00-11:00): hotels and high-end restaurants ──
                .stop("Hotel Arts",         s -> s.at(41.3858, 2.1968).demand(6)
                        .serviceTime(Duration.ofMinutes(15))
                        .openFrom(LocalTime.of(8, 0)).closeAt(LocalTime.of(11, 0)))
                .stop("Hotel W Barcelona",   s -> s.at(41.3736, 2.1884).demand(5)
                        .serviceTime(Duration.ofMinutes(15))
                        .openFrom(LocalTime.of(8, 0)).closeAt(LocalTime.of(11, 0)))
                .stop("Hotel Mandarin",      s -> s.at(41.3936, 2.1612).demand(4)
                        .serviceTime(Duration.ofMinutes(10))
                        .openFrom(LocalTime.of(8, 30)).closeAt(LocalTime.of(11, 0)))
                .stop("Hotel Majestic",      s -> s.at(41.3923, 2.1651).demand(3)
                        .serviceTime(Duration.ofMinutes(10))
                        .openFrom(LocalTime.of(8, 30)).closeAt(LocalTime.of(10, 30)))
                .stop("Hotel Claris",        s -> s.at(41.3946, 2.1630).demand(3)
                        .serviceTime(Duration.ofMinutes(10))
                        .openFrom(LocalTime.of(8, 0)).closeAt(LocalTime.of(10, 30)))

                // ── Midday wave (11:00-14:00): supermarkets and caterers ──────────
                .stop("Caprabo Eixample",    s -> s.at(41.3888, 2.1524).demand(8)
                        .serviceTime(Duration.ofMinutes(20))
                        .openFrom(LocalTime.of(11, 0)).closeAt(LocalTime.of(14, 0)))
                .stop("Mercadona Gràcia",    s -> s.at(41.4051, 2.1561).demand(7)
                        .serviceTime(Duration.ofMinutes(20))
                        .openFrom(LocalTime.of(11, 0)).closeAt(LocalTime.of(14, 0)))
                .stop("Catering Poblenou",   s -> s.at(41.4015, 2.1978).demand(6)
                        .serviceTime(Duration.ofMinutes(15))
                        .openFrom(LocalTime.of(11, 30)).closeAt(LocalTime.of(13, 30)))
                .stop("Supermercado Sants",  s -> s.at(41.3740, 2.1385).demand(5)
                        .serviceTime(Duration.ofMinutes(15))
                        .openFrom(LocalTime.of(11, 0)).closeAt(LocalTime.of(14, 0)))

                // ── Flexible stops (no time window — delivered whenever convenient) ─
                .stop("Bodega Barceloneta",  s -> s.at(41.3802, 2.1894).demand(4)
                        .serviceTime(Duration.ofMinutes(10)))
                .stop("Bar Raval",           s -> s.at(41.3793, 2.1644).demand(3)
                        .serviceTime(Duration.ofMinutes(8)))
                .stop("Restaurante Les Corts",s-> s.at(41.3844, 2.1317).demand(4)
                        .serviceTime(Duration.ofMinutes(10)))
                .stop("Café Sarrià",         s -> s.at(41.4007, 2.1339).demand(2)
                        .serviceTime(Duration.ofMinutes(8)))
                .stop("Mercat Sant Martí",   s -> s.at(41.4001, 2.1967).demand(5)
                        .serviceTime(Duration.ofMinutes(12)))
                .stop("Colmado Nou Barris",  s -> s.at(41.4380, 2.1793).demand(3)
                        .serviceTime(Duration.ofMinutes(8)))
                .stop("Pastisseria Horta",   s -> s.at(41.4259, 2.1712).demand(2)
                        .serviceTime(Duration.ofMinutes(5)))
                .stop("Forn de Pa Gràcia",   s -> s.at(41.4022, 2.1544).demand(2)
                        .serviceTime(Duration.ofMinutes(5)))
                .stop("Xarcuteria Eixample", s -> s.at(41.3864, 2.1502).demand(3)
                        .serviceTime(Duration.ofMinutes(8)))

                .distances(DistanceSource.haversine())

                .goal(Goals.totalDistance())

                .solver()
                .timeLimit(Duration.ofSeconds(30))
                .firstSolution(Strategy.SAVINGS)
                .improveWith(Metaheuristic.GUIDED_LOCAL_SEARCH)
                .solve();

        // ── Results ───────────────────────────────────────────────────────────
        System.out.printf("%nStatus : %s%n", plan.status());

        if (!plan.isFeasible()) {
            System.out.println("No solution found.");
            return;
        }

        plan.objective().ifPresent(d ->
            System.out.printf("Total distance : %.1f km across all vehicles%n", d / 1000.0));

        System.out.println();

        for (Route r : plan.routes()) {
            if (r.stops().isEmpty()) continue;
            System.out.printf("%-14s (load %2d/%-2d): depot → %s → depot  [%.1f km]%n",
                    r.vehicle(), r.load(),
                    r.vehicle().startsWith("Large") ? 25 : 15,
                    String.join(" → ", r.stops()),
                    r.distanceMeters() / 1000.0);
            r.breaks().forEach(b -> System.out.printf("%-14s break %s–%s%n", "", b.start(), b.end()));
        }

        if (!plan.unassignedStops().isEmpty()) {
            System.out.println("\nUnassigned stops: " + plan.unassignedStops());
        } else {
            System.out.println("\nAll 18 stops successfully assigned.");
        }

        // Per-vehicle statistics
        System.out.println("\n── Vehicle utilization ──────────────────────────────────────────────");
        System.out.printf("%-14s  %-6s  %-8s  %-6s%n", "Vehicle", "Stops", "Distance", "Load");
        System.out.println("-".repeat(42));
        for (Route r : plan.routes()) {
            System.out.printf("%-14s  %-6d  %-8.1f  %-6d%n",
                    r.vehicle(), r.stops().size(), r.distanceMeters() / 1000.0, r.load());
        }
    }
}

    Cargo loading¶

    Nine cargo lots compete for three containers with weight limits. The program loads the combination with the highest total value and lists what stays behind.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.CargoLoadingMultipleKnapsack
    Source: CargoLoadingMultipleKnapsack.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.Optimize;
import io.github.janglada.orkit.knapsack.BinAssignment;
import io.github.janglada.orkit.knapsack.MultipleKnapsackSolution;

import java.time.Duration;

/**
 * Cargo loading — assign freight to multiple containers/trucks to maximize total
 * shipped value without exceeding any container's weight capacity.
 *
 * <p>Demonstrates: multiple knapsacks, profit (value) maximization, per-bin
 * capacity constraints, items that may be left behind when capacity is tight.
 *
 * <p>Containers (weight capacity, in tons):
 * <ul>
 *   <li>C1 — 15 t</li>
 *   <li>C2 — 20 t</li>
 *   <li>C3 — 10 t</li>
 * </ul>
 * Each cargo item has a declared value (profit) and weight; the solver picks which
 * container (if any) holds each item so that total shipped value is maximized.
 *
 * Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.CargoLoadingMultipleKnapsack
 */
public class CargoLoadingMultipleKnapsack {

    /**
     * Builds the cargo-loading multiple-knapsack model, solves it with CP-SAT, and
     * prints the per-container assignments, total shipped profit, and any items
     * left behind due to capacity.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═════════════════════════════════════════════╗");
        System.out.println("║  Cargo Loading — Multiple Knapsack          ║");
        System.out.println("╚═════════════════════════════════════════════╝");

        MultipleKnapsackSolution solution = Optimize.multipleKnapsack()
                .bin("C1", b -> b.capacity(15))
                .bin("C2", b -> b.capacity(20))
                .bin("C3", b -> b.capacity(10))

                .item("Steel-Coils",   i -> i.profit(60).weight(12))
                .item("Electronics",   i -> i.profit(90).weight(6))
                .item("Machinery",     i -> i.profit(120).weight(10))
                .item("Textiles",      i -> i.profit(40).weight(5))
                .item("Chemicals",     i -> i.profit(70).weight(8))
                .item("Furniture",     i -> i.profit(50).weight(7))
                .item("Foodstuff",     i -> i.profit(30).weight(4))
                .item("Oversize-Rig",  i -> i.profit(150).weight(18))   // fits only C2
                .item("Pharma",        i -> i.profit(80).weight(3))

                .solver()
                .timeLimit(Duration.ofSeconds(10))
                .workers(8)
                .solve();

        // ── Results ───────────────────────────────────────────────────────────
        System.out.printf("%nStatus      : %s%n", solution.status());
        System.out.printf("TotalProfit : %d%n%n", solution.totalProfit());

        System.out.println("── Container assignments ─────────────────────────────────────");
        System.out.printf("%-5s  %-14s  %-8s  %-8s%n", "Bin", "Items", "Load", "Profit");
        System.out.println("-".repeat(40));
        for (BinAssignment a : solution.assignments()) {
            System.out.printf("%-5s  %-14s  %-8d  %-8d%n",
                    a.bin(),
                    a.items().isEmpty() ? "-" : String.join(",", a.items()),
                    a.usedCapacity(),
                    a.profit());
        }

        if (!solution.unassignedItems().isEmpty()) {
            System.out.printf("%nLeft behind: %s%n", solution.unassignedItems());
        }
    }
}

    Warehouse container loading¶

    Eight boxes are placed in two containers in three dimensions. The goal is to use as few containers as possible. The program prints the position of every box.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.WarehouseContainerPacking
    Source: WarehouseContainerPacking.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.packing.ContainerAssignment;
import io.github.janglada.orkit.packing.Goals;
import io.github.janglada.orkit.packing.PackingBuilder;
import io.github.janglada.orkit.packing.PackingSolution;

import java.time.Duration;

/**
 * Warehouse container loading — pack boxes into the minimum number of containers while
 * respecting 3D non-overlap placement and per-container weight limits.
 *
 * <p>Demonstrates: 3D bin packing, container minimization, axis-aligned placement with
 * no-overlap constraints, boxes that may be left unassigned when they do not fit.
 *
 * <p>Containers (interior L x W x H, max weight):
 * <ul>
 *   <li>C1 — 12 x 8 x 6, max weight 30</li>
 *   <li>C2 — 12 x 8 x 6, max weight 30</li>
 * </ul>
 * Each box has a length, width, height, and weight; the solver chooses a container and a
 * placement (x, y, z origin) for every box that fits, minimizing the containers used.
 *
 * Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.WarehouseContainerPacking
 */
public class WarehouseContainerPacking {

    /**
     * Builds the container-loading model, solves it with CP-SAT, and prints the
     * per-container placements (with box coordinates) and any boxes left behind.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═════════════════════════════════════════════╗");
        System.out.println("║  Warehouse Container Loading — 3D Bin Pack  ║");
        System.out.println("╚═════════════════════════════════════════════╝");

        PackingSolution solution = new PackingBuilder()
                .goal(Goals.minimizeContainersUsed())
                .container("C1", c -> c.length(12).width(8).height(6).maxWeight(30))
                .container("C2", c -> c.length(12).width(8).height(6).maxWeight(30))

                .box("Pallet-A",   b -> b.length(4).width(4).height(3).weight(8))
                .box("Pallet-B",   b -> b.length(4).width(4).height(3).weight(8))
                .box("Crate-C",    b -> b.length(3).width(2).height(2).weight(4))
                .box("Crate-D",    b -> b.length(3).width(2).height(2).weight(4))
                .box("Box-E",      b -> b.length(2).width(2).height(2).weight(2))
                .box("Box-F",      b -> b.length(2).width(2).height(2).weight(2))
                .box("Box-G",      b -> b.length(2).width(1).height(1).weight(1))
                .box("Oversize-H", b -> b.length(13).width(1).height(1).weight(1))   // fits nowhere
                .solver()
                .timeLimit(Duration.ofSeconds(10))
                .workers(8)
                .solve();

        // ── Results ───────────────────────────────────────────────────────────
        System.out.printf("%nStatus         : %s%n", solution.status());
        System.out.printf("Containers used : %d%n", solution.containersUsed());
        System.out.printf("Objective       : %s%n%n",
                solution.objective().isPresent() ? solution.objective().getAsDouble() : "n/a");

        System.out.println("── Container placements ──────────────────────────────────────");
        System.out.printf("%-5s  %-10s  %-18s  %-10s  %-10s%n",
                "Cont", "Boxes", "Placements", "UsedVol", "UsedWt");
        System.out.println("-".repeat(60));
        for (ContainerAssignment a : solution.assignments()) {
            String placements = a.boxes().isEmpty() ? "-" :
                    a.boxes().stream()
                            .map(p -> p.boxId() + "@(" + p.x() + "," + p.y() + "," + p.z() + ")")
                            .reduce((x, y) -> x + " " + y).orElse("-");
            System.out.printf("%-5s  %-10d  %-18s  %-10d  %-10d%n",
                    a.containerId(),
                    a.boxes().size(),
                    placements,
                    a.usedVolume(),
                    a.usedWeight());
        }

        if (!solution.unassignedBoxes().isEmpty()) {
            System.out.printf("%nLeft behind: %s%n", solution.unassignedBoxes());
        }
    }
}

    Clinic appointment booking¶

    Eight appointments share three rooms, and one of them also needs a surgeon. Each appointment has a penalty for being left out, and the solver keeps the total penalty as low as possible.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.ClinicAppointmentBooking
    Source: ClinicAppointmentBooking.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.Optimize;
import io.github.janglada.orkit.booking.BookingSolution;
import io.github.janglada.orkit.booking.AppointmentAssignment;
import io.github.janglada.orkit.booking.Goals;
import io.github.janglada.orkit.booking.TimeSlot;

import java.time.Duration;
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.util.List;

/**
 * Clinic appointment booking — assign patient appointments to exam rooms so that
 * the total unscheduled-penalty is minimized, while no two appointments on the same
 * room ever overlap and every appointment stays within its room's availability window.
 *
 * <p>Demonstrates: optional CP-SAT interval variables, per-resource {@code NoOverlap},
 * single-slot availability windows, and penalty-weighted objective selection when
 * capacity is tight.
 *
 * <p>Three exam rooms, each available 08:00–16:00 (an 8-hour slot); eight appointments
 * of varying durations and priorities. When total demand exceeds capacity the solver
 * drops the lowest-priority appointments first.
 *
 * Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.ClinicAppointmentBooking
 */
public class ClinicAppointmentBooking {

    /**
     * Builds the clinic-booking model, solves it with CP-SAT, and prints the per-room
     * schedule plus the list of appointments that could not be accommodated.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═════════════════════════════════════════════╗");
        System.out.println("║  Clinic Appointment Booking                 ║");
        System.out.println("╚═════════════════════════════════════════════╝");

        LocalDate day = LocalDate.of(2025, 3, 10);
        LocalDateTime open  = day.atTime(8, 0);
        LocalDateTime close = day.atTime(16, 0);
        TimeSlot roomHours = new TimeSlot(open, close);

        BookingSolution solution = Optimize.booking()
                .horizon(day, 1)
                .goal(Goals.minimizeUnscheduledPenalty())
                .resource("Room-A", r -> r.available(roomHours))
                .resource("Room-B", r -> r.available(roomHours))
                .resource("Room-C", r -> r.available(roomHours))
                .resource("Surgeon", r -> r.available(new TimeSlot(day.atTime(10, 0), close)))

                .appointment("P1-Checkup",      a -> a.duration(Duration.ofMinutes(30)).requiresAnyOf("Room-A", "Room-B", "Room-C").penaltyIfUnscheduled(5))
                .appointment("P2-Vaccination",  a -> a.duration(Duration.ofMinutes(15)).requiresAnyOf("Room-A", "Room-B", "Room-C").penaltyIfUnscheduled(2))
                .appointment("P3-Consultation", a -> a.duration(Duration.ofMinutes(60)).requiresAnyOf("Room-A", "Room-B", "Room-C").penaltyIfUnscheduled(10))
                .appointment("P4-MinorSurgery", a -> a.duration(Duration.ofMinutes(120)).requiresAnyOf("Room-A", "Room-B").alsoRequiresAnyOf("Surgeon").penaltyIfUnscheduled(20))
                .appointment("P5-FollowUp",     a -> a.duration(Duration.ofMinutes(20)).requiresAnyOf("Room-A", "Room-B", "Room-C").penaltyIfUnscheduled(3))
                .appointment("P6-Checkup",      a -> a.duration(Duration.ofMinutes(30)).requiresAnyOf("Room-A", "Room-B", "Room-C").penaltyIfUnscheduled(5))
                .appointment("P7-Consultation",a -> a.duration(Duration.ofMinutes(90)).requiresAnyOf("Room-A", "Room-C").penaltyIfUnscheduled(15))
                .appointment("P8-Vaccination",  a -> a.duration(Duration.ofMinutes(15)).requiresAnyOf("Room-A", "Room-B", "Room-C").penaltyIfUnscheduled(2))

                .solver()
                .timeLimit(Duration.ofSeconds(10))
                .workers(8)
                .solve();

        // ── Results ───────────────────────────────────────────────────────────
        System.out.printf("%nStatus   : %s%n", solution.status());
        solution.objective().ifPresent(v -> System.out.printf("Objective: %.0f%n", v));
        System.out.printf("Runtime  : %d ms%n%n", solution.runtime().toMillis());

        System.out.println("── Room schedules ────────────────────────────────────────────");
        for (String room : List.of("Room-A", "Room-B", "Room-C")) {
            System.out.printf("%n%s:%n", room);
            List<AppointmentAssignment> on = solution.assignmentsOn(room);
            if (on.isEmpty()) {
                System.out.println("  (no appointments)");
                continue;
            }
            on.stream()
                    .sorted(java.util.Comparator.comparing(AppointmentAssignment::start))
                    .forEach(a -> System.out.printf("  %s  %s–%s  (%d min)%s%n",
                            pad(a.appointmentId(), 18), a.start().toLocalTime(), a.end().toLocalTime(),
                            a.duration().toMinutes(),
                            a.resourceIds().size() > 1 ? "  with " + String.join(", ", a.resourceIds().subList(1, a.resourceIds().size())) : ""));
        }

        if (!solution.unscheduled().isEmpty()) {
            System.out.printf("%n── Unscheduled ───────────────────────────────────────────────%n");
            solution.unscheduled().forEach(id -> System.out.println("  " + id));
        }
    }

    private static String pad(String s, int width) {
        StringBuilder sb = new StringBuilder(s);
        while (sb.length() < width) sb.append(' ');
        return sb.toString();
    }
}

    Steel roll cutting¶

    Beams of five lengths are cut from three kinds of stock. The blade removes 3 mm at every cut. The goal is to waste as little steel as possible.

    mvn -q test-compile exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.SteelRollCuttingStock
    Source: SteelRollCuttingStock.java 
    package io.github.janglada.orkit.examples;

import io.github.janglada.orkit.cutting.CuttingBuilder;
import io.github.janglada.orkit.cutting.CuttingSolution;
import io.github.janglada.orkit.cutting.Goals;
import io.github.janglada.orkit.cutting.StockAssignment;
import io.github.janglada.orkit.cutting.StockAssignment.CutPiece;

import java.time.Duration;

/**
 * Steel roll cutting-stock — cut demanded piece lengths from steel rolls of three
 * available cross-sections (6 m, 8 m, 10 m), minimizing total trim waste.
 *
 * <p>Demonstrates: 1D cutting stock, per-roll NoOverlap, required pieces, quantity
 * expansion for both stock and pieces, and the {@link Goals#minimizeWaste()} objective.
 *
 * <p>Run: mvn exec:java -Dexec.mainClass=io.github.janglada.orkit.examples.SteelRollCuttingStock
 */
public class SteelRollCuttingStock {

    /**
     * Builds the cutting-stock model, solves it with CP-SAT, and prints the per-roll
     * cut layout and total trim waste.
     *
     * @param args unused command-line arguments
     */
    public static void main(String[] args) {
        System.out.println("╔═════════════════════════════════════════════╗");
        System.out.println("║  Steel Roll Cutting Stock — 1D              ║");
        System.out.println("╚═════════════════════════════════════════════╝");

        CuttingSolution solution = new CuttingBuilder()
                .stock("S6",  s -> s.length(6000).cost(60).quantity(2))
                .stock("S8",  s -> s.length(8000).cost(85).quantity(2))
                .stock("S10", s -> s.length(10000).cost(110).quantity(2))

                .required("beam-2200", p -> p.length(2200).quantity(6))
                .required("beam-1800", p -> p.length(1800).quantity(4))
                .required("beam-1500", p -> p.length(1500).quantity(3))
                .required("beam-900",  p -> p.length(900).quantity(5))
                .required("beam-600",  p -> p.length(600).quantity(4))

                .kerf(3)                                   // saw blade width, in mm
                .goal(Goals.minimizeWaste())
                .solver()
                .timeLimit(Duration.ofSeconds(15))
                .workers(8)
                .solve();

        System.out.printf("%nStatus        : %s%n", solution.status());
        System.out.printf("StockUsed     : %d roll(s)%n", solution.totalStockUsed());
        System.out.printf("TotalWaste    : %d mm (kerf loss included)%n%n", solution.totalWaste());

        System.out.println("── Roll assignments ───────────────────────────────────────────");
        System.out.printf("%-8s  %-8s  %-7s  %s%n", "Roll", "Length", "Waste", "Pieces (id@start..end)");
        System.out.println("-".repeat(60));
        for (StockAssignment a : solution.assignments()) {
            String pieces = a.pieces().isEmpty() ? "-" : renderPieces(a.pieces());
            System.out.printf("%-8s  %-8d  %-7d  %s%n",
                    a.stockId(),
                    a.length(),
                    a.waste(),
                    pieces);
        }

        if (!solution.unplacedPieces().isEmpty()) {
            System.out.printf("%nUnplaced: %s%n", solution.unplacedPieces());
        }
    }

    private static String renderPieces(java.util.List<CutPiece> cuts) {
        java.util.List<CutPiece> sorted = new java.util.ArrayList<>(cuts);
        sorted.sort(java.util.Comparator.comparingLong(CutPiece::start));
        java.util.StringJoiner sj = new java.util.StringJoiner(", ");
        for (CutPiece c : sorted) {
            sj.add(c.pieceId() + "@" + c.start() + ".." + (c.start() + c.length()));
        }
        return sj.toString();
    }
